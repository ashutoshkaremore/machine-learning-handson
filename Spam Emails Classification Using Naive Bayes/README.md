<h2>Project : Spam Classification using Naive Bayes</h2>

The Spam Mail Classification project is a web-based application that uses ``Naive Bayes Machine Learning Algorithm`` to classify emails as spam or ham. It features a Flask backend, a frontend created with HTML, CSS, and JavaScript.

<h3>
  Project Features : <br>
</h3>
<b>Email Classification:</b> Categorizes emails as spam or ham.<br>
<b>Machine Learning Model:</b> Using a Naive Bayes Machine Learning Model to classify emails, trained on large dataset

<h3>
  Technologies Used : <br>
</h3>

``scikit-learn`` , ``Naive Bayes Algorithm``, ``Numpy``, ``Pandas``, ``Flask``, ``HTML``, ``CSS``
